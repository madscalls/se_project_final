# Introspective Color

This is a color coordinated photo sharing app. It is meant to calm and relax the brain by providing minimal verbage. Simply color grouped photos, with simple hashtag for search optimization. The sleek interface is easy on the eyes for a less overwhelming experience.

Right now I've been letting friends and family know about what I've made and they have slowly been adding scenic photos and I find it to be a super fun way to interact with them without words. As a very visually inclined individual this has been a really fun project to execute.

## Some features:

-Dropbox for easy uploads
-sign-in and sign-up with authorization & hashing
-Error handling
-Cloudinary & Multer integration for validation type and size
-Color coordinated oganization for every mood
-Tags for search optimization -- in progress
-Profile page & avatar for personalization -- in progress
-Fun color css animations/details for a little bit of serotonin
